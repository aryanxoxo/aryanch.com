What I worked on

RF hardware for a satellite that has to work far away.

/ 01

System Context

ALEASAT pairs an onboard camera with ground-station infrastructure so users can request targeted Earth imagery and downlink the data directly from the satellite. It is being developed as a precursor to broader disaster-monitoring satellite capability.

My Role

As a Spacecraft Hardware Developer, I contributed to the communication subsystem, integrated the RF communications board and antenna deployer board, and helped validate that the boards operated reliably together.

Technical Work

  • Helped design a half-duplex radio system using OpenLST software-defined radio and the CC1110 low-power SoC.
  • Automated link budget calculations in Python to improve communication analysis and iteration speed.
  • Supported reliability testing for the antenna deployment mechanism.

Result

The communications work improved link performance and helped reduce bit error rate while giving the team a more repeatable path for RF analysis, board integration, and ground-station planning.
