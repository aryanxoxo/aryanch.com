Equation Explorer

dM/dt = gamma * M x Beff
Beff(z,t) = [B1(t), 0, Gz * z]
slice_width ~= RF_bandwidth / (gamma_bar * Gz)
flip_angle_center ~= gamma * integral(B1(t) dt)
Flip angleScales RF pulse area. A 90 degree pulse creates transverse signal; a 180 degree pulse inverts Mz.
RF durationControls pulse length and peak B1. Longer pulses usually need lower B1 for the same flip angle.
Gz gradientMaps position to resonance frequency. Stronger Gz makes the same RF bandwidth select a thinner slice.
Slice thicknessSets the target slab width. The model computes bandwidth from thickness when the preset uses automatic TBW.
TBWTime-bandwidth product. Higher values sharpen edges, but add structure to the pulse and profile.
